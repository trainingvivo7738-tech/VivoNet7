# VivoNet — versión 107

Proyecto web estático de VivoNet con Vigo integrado.

## Archivos principales
- `index.html`: pantalla principal aprobada de VivoNet v107.
- `vigo.html`: página de Vigo.
- `service-worker.js`: caché de la aplicación y sus páginas principales.
- `manifest.webmanifest`: configuración de instalación PWA.
- Iconos PNG y SVG para navegador y acceso directo.

## Cambios incluidos en v107
- Separación entre secciones: 12 px.
- Separación entre la última sección y los botones inferiores: 26 px.
- Se eliminó la flecha rosa de «¿Sabías que…?».
- Al tocar la tarjeta, cambia la curiosidad y su consejo de venta.

`index.html` corresponde exactamente al HTML independiente aprobado de v107. Se eliminó el HTML antiguo duplicado para evitar que se abra una versión anterior por error.
